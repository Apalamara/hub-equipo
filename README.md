# El Hub — app del equipo

App de los voluntarios de El Hub, Saddleback Buenos Aires: el domingo, los
turnos, las entregas y el manual. Se publica en GitHub Pages:
**https://apalamara.github.io/hub-equipo/**

## Esto es un espejo, no la fuente

No se edita acá. La fuente es `app/index.html` del repo de trabajo (privado),
y esto se actualiza corriendo `app/publicar.sh` desde allá.

La página no tiene datos adentro: los lee de un Google Sheet, y solo con la
clave que viene en el link del equipo. Sin ese link muestra un cartel y nada más.
